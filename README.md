# AadhaarTools

Binary tools and dependencies required for the AadhaarMasking service:

- Poppler (including pdftoppm): PDF rendering toolchain for converting PDF pages to images.
- Tesseract-OCR: OCR engine and language trained data for text and bounding-box detection.

### Key Executables
- Poppler\Library\bin\pdftoppm.exe
- Tesseract-OCR\tesseract.exe
